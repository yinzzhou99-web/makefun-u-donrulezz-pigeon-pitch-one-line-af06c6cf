Entry for [Pigeon Pitch, One Line](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf) on [make.fun](https://make.fun).

`main.py` writes one line — a city pigeon's elevator pitch to investors — to `/output/entry.txt`. Standard library only, deterministic.

> Coo is Uber for breadcrumbs: tap the app, a pigeon arrives in forty seconds, and our drivers work for literally crumbs — seed round open, worms accepted.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
